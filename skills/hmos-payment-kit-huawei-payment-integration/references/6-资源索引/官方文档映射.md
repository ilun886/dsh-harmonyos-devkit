# 官方文档映射

## 使用原则

- 以华为官方公开文档为最高优先级。
- 若官网内容与历史离线资料不一致，以官网当前定义为准。
- `references/` 中的说明负责提供导航、约束和可直接复用的示例出处，不直接替代官方原文。

## 核心入口

### Payment Kit 接口总入口

- 文档：`https://developer.huawei.com/consumer/cn/doc/harmonyos-references/payment-api`
- 用途：查询 Payment Kit 端侧与云侧 API 参考。
- 适用问题：
  - 端侧接口参数结构
  - 预下单、预签约、合单、回调相关 REST 参考
  - 错误码与接口字段定义

### 签名与验签规则

- 文档：`https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-signature-rule-0000001538533912`
- 用途：核对排序、拼接、签名算法与验签逻辑。
- 适用问题：
  - 为什么会报签名错误
  - 空字符串和 `null` 是否参与签名
  - 回调验签原文和公钥如何使用

## 使用建议

- 讲“是什么”时优先指向官方文档。
- 讲“怎么接”和“怎么排错”时优先结合本地 `references/`。
- 给代码时优先引用本地真实示例，再补充该示例对应的官方参考入口。
