# 沙盒联调与生产切换

## 沙盒联调

### 必备条件

- 使用沙盒专用 `mercNo`、`authId`、证书和测试账号。
- 客户端使用 debug 签名。
- 服务端和客户端明确当前请求发往沙盒环境。

### 关键参数

- 沙盒域名：`https://petalpay-developer-sandbox.cloud.huawei.com.cn`
- 基础支付或其他预处理请求中的 `reserved` 建议携带：`{"sandbox_flag": true}`

### 联调检查

- 是否真的切到沙盒域名。
- 是否使用了沙盒证书和沙盒商户配置。
- 是否用真实服务端生成的 `orderStr` / `contractStr`。
- 是否完成了回调验签与幂等。

## 生产切换

### 上线前清单

1. 已切换生产域名与生产证书。
2. 已移除沙盒标识和沙盒账号配置。
3. 回调地址为公网 HTTPS，TLS 版本满足要求。
4. 回调验签和幂等已完成压测。
5. 查单、退款、告警和重试链路已验证。

### 高频失误

- 代码切了生产，但证书还在用沙盒。
- 生产环境还保留 `sandbox_flag`。
- `appId`、`mercNo`、`authId` 仍指向旧环境。
- 回调域名可以浏览器访问，但服务端 TLS 或防火墙策略不满足支付回调要求。
