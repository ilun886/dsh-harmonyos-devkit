# 签约代扣接入指南

## 最小闭环

1. 服务端调用预签约接口。
2. 服务端组装并返回 `contractStr`。
3. 客户端拉起签约收银台。
4. 服务端接收签约结果回调并验签。
5. 签约成功后，再进入后续代扣申请流程。

## 关键字段

- `contractStr`
- `preSignNo`
- `planId`
- `mercContractCode`

## 关键规则

- `contractStr` 必须由服务端生成。
- 签约成功不等于后续代扣成功。
- 签约回调与代扣回调都要走验签和幂等。

## 客户端形态

- 标准 App：`paymentService.requestContract(...)`
- ASCF 元服务：`has.requestContract(...)`

## 服务端形态

- Java SDK 可通过预签约接口获取 `preSignNo`。
  - 直连商户预签约：`/api/v2/contract/presign/app`
  - 平台类商户/服务商：`/api/v1/partner/contract/presign/app`
- 校验成功后通过 SDK 构建 `contractStr` 返回客户端。
