# 退款典型问题

## TP-REF-001: 退款返回账户余额不足 CHECK_ACCOUNT_BALANCE

- **业务场景**: 退款
- **错误码/现象**: subCode: CHECK_ACCOUNT_BALANCE, subDesc: 账户余额不足

**常见原因**
支付订单 T+1 结算后资金已划付到商户结算账户，支付账户余额为 0，退款只能从支付账户扣款，因此余额不足时退款失败。

**解决步骤**

1. 商户平台查询支付账户余额与结算明细，确认订单已结算
2. 手动给支付账户充值，或调高留存金额（留存金额不能用于转账）
3. 重新发起退款；若原订单已结算较久，可联系用户走线下转账

**官方文档**

- [账户余额查询](https://developer.huawei.com/consumer/cn/doc/pay-docs/hwzf-zhanghuyue-0000002344207501)
- [结算手续费规则](https://developer.huawei.com/consumer/cn/doc/pay-docs/hwzf-jiesuanshouxufei-0000001200646826)

## TP-REF-002: 退款返回操作未授权

- **业务场景**: 退款
- **错误码/现象**: 退款接口返回"操作未授权"

**常见原因**
商户未在商户平台完成退款 API 授权配置，或退款权限未开通。

**解决步骤**

1. 登录商户平台，检查退款 API 授权状态
2. 参考官方文档完成退款授权配置
3. 重新发起退款请求

**官方文档**

- [API 授权退款](https://developer.huawei.com/consumer/cn/doc/pay-docs/hwzf-apituikuan-0000002371871965)

## TP-REF-003: 退款 resultCode 非 000000 是否可换单号重发

- **业务场景**: 退款
- **错误码/现象**: 退款响应 resultCode 非 000000

**常见原因**
退款请求未成功受理，订单状态未变更，可换单号重新发起。

**解决步骤**

1. 确认退款响应 resultCode 非 000000
2. 生成新的退款订单号
3. 重新发起退款请求

**官方文档**

- [退款接口文档](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/payment-rest-overview)

## TP-REF-004: 退款接口字段缺失原始订单号

- **业务场景**: 退款
- **错误码/现象**: 退款返回 400000 业务处理失败

**常见原因**
退款接口响应字段原始订单号非必填，回调当前不返回原始订单号。

**解决步骤**

1. 自行关联记录原始订单号及退款订单号
2. 发起退款请求成功后，通过退款订单号在开发者的系统找到原订单信息

**官方文档**

- [退款接口参数说明](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/payment-rest-overview)

## TP-REF-005: 无法原路退款时通过支付账户转账退款

- **业务场景**: 退款
- **错误码/现象**: 原路退款失败，需通过支付账户转账

**常见原因**
原支付渠道不支持原路退款，或退款时间超出原路退款期限，需通过支付账户余额转账给用户。

**解决步骤**

1. 确认支付账户余额充足
2. 使用转账接口将资金转给用户
3. 记录转账凭证，与用户对账

**官方文档**

- [转账接口文档](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/payment-rest-overview)

## TP-REF-006: RSAUtils.verifyRSASignWithPSS 方法使用

- **业务场景**: 退款
- **错误码/现象**: 退款验签方法选择疑问

**常见原因**
商户对退款回调验签方法选择有误，verifyRSASignWithPSS 用于 RSA 签名验证，非退款专用方法。

**解决步骤**

1. 确认使用正确的验签方法（SM2 或 RSA）
2. 参考官方文档选择对应验签方式
3. 核对公钥与签名算法匹配

**官方文档**

- [签名与验签规则](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/payment-certificates-config)

## TP-REF-007: 退款回调重复推送 5 次

- **业务场景**: 退款
- **错误码/现象**: 退款回调重复推送

**常见原因**
商户回调响应格式不符合要求（非 application/json 或未返回成功响应体），触发华为支付重试机制。

**解决步骤**

1. 检查回调响应 Content-Type 为 application/json
2. 确认响应体为 {"resultCode":"000000","resultDesc":"Success."}
3. 确保回调处理逻辑幂等，避免重复处理

**官方文档**

- [回调通知处理](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/payment-callback)
