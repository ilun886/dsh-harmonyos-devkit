# 子商户进件典型问题

## TP-SUB-001: 进件文件加密失败 INVALID_PARAMETER decrypt failed

- **业务场景**: 子商户进件
- **错误码/现象**: subCode: INVALID_PARAMETER, subDesc: decrypt failed

**常见原因**
进件接口中文件内容（fileContent）加密失败，通常是因为：文件内容未做 base64 编码、加密前缀不正确（应为encrypt0-SM41-）、或加密方式与平台要求不匹配。

**解决步骤**

1. 确认文件内容先做 SM4 加密，再做 base64 编码
2. 检查加密前缀是否为 `encrypt0-SM41-`
3. 不要用前缀做判断，改用编码方式标识
4. 重新提交进件请求

**官方文档**

- [子商户进件接口](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-partner-merc-manage-0000001642621741)

## TP-SUB-002: 进件状态枚举 MANUAL_PROCESSING 文档缺失

- **业务场景**: 子商户进件
- **错误码/现象**: 进件状态返回 MANUAL_PROCESSING，文档中未定义

**常见原因**
进件状态枚举中 `MANUAL_PROCESSING` 表示"挂起，等待人工介入"，官方文档可能未完整列出此状态。

**解决步骤**

1. MANUAL_PROCESSING = 挂起，需人工审核介入
2. 联系华为支付运营团队确认挂起原因
3. 按运营要求补充材料或修改信息
4. 审核通过后状态自动流转

**官方文档**

- [子商户进件接口](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-partner-merc-manage-0000001642621741)

## TP-SUB-003: 进件 v1/v2 接口兼容性

- **业务场景**: 子商户进件
- **错误码/现象**: 商户使用 v1 接口进件，不确定是否需要升级到 v2

**常见原因**
华为支付子商户进件接口有 v1 和 v2 两个版本，v2 在数据格式上有调整。v1 接口仍可用，但后续新功能将在 v2 上演进。

**解决步骤**

1. v1 接口仍可正常使用，无需强制升级
2. 如需使用新功能（如文件标识方式），可升级到 v2
3. v2 版本使用文件上传接口获取文件 ID，传递文件 ID 而非直接传文件内容
4. 参考 v2 接口文档调整请求参数

**官方文档**

- [子商户进件接口](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-partner-merc-manage-0000001642621741)

## TP-SUB-004: 进件银行选择（杭州银行在"其他银行"下）

- **业务场景**: 子商户进件
- **错误码/现象**: 进件时结算银行列表中找不到"杭州银行"

**常见原因**
杭州银行等部分地方性银行在进件平台的银行列表中统一归类在"其他银行"下，需先选择"其他银行"再选择具体银行。

**解决步骤**

1. 在结算银行列表中先选择"其他银行"
2. 展开后选择具体银行（如杭州银行）
3. 如仍无法找到，联系华为支付运营确认银行名称

**官方文档**

- [子商户进件指南](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-partner-merc-manage-0000001642621741)

## TP-SUB-005: 进件审核中如何修改资料

- **业务场景**: 子商户进件
- **错误码/现象**: 进件审核中需要修改资料，不确定如何操作

**常见原因**
进件处于"审核中"状态时不支持直接修改资料。需要先撤销当前进件申请，再重新提交修改后的资料。

**解决步骤**

1. 调用撤销接口撤销当前进件申请
2. 修改需要更正的资料信息
3. 重新提交进件请求
4. 注意：审核中不可修改，待激活前可修改，待激活后不允许修改

**官方文档**

- [子商户进件接口](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-partner-merc-manage-0000001642621741)

## TP-SUB-006: 子商户 API 入网接口

- **业务场景**: 子商户进件
- **错误码/现象**: 商户希望通过 API 实现子商户自动化入网

**常见原因**
商户需要将子商户入网流程集成到自身系统中，实现用户通过元服务或 App 直接完成入网，而非手动在商户平台操作。

**解决步骤**

1. 使用子商户 API 入网接口（partner-merc-manage）
2. 参考接口文档实现进件、查询、撤销等操作
3. 文件上传使用文件上传接口获取文件 ID
4. 进件状态通过查询接口轮询

**官方文档**

- [子商户 API 入网](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-partner-merc-manage-0000001642621741)
