# 回调与幂等常见问题

## TP-CB-001: 为什么一直收不到回调？

优先检查：

- `callbackUrl` 是否公网 HTTPS。
- 是否误填了内网地址、localhost 或测试环境地址。
- 服务端 TLS、证书或防火墙策略是否阻断。

## TP-CB-002: 为什么回调会重复推送？

原因：

- 业务处理超时。
- 没有在 3 秒内返回标准成功报文。
- 返回体不符合要求。

## TP-CB-003: 为什么会重复支付、重复退款？

原因：

- 没有幂等控制。

处理：

- 以订单号、通知唯一标识或 `callbackId` 做幂等键。
- 已处理过的通知直接返回成功。

## TP-CB-004: 为什么验签成功了还是不建议直接更新状态？

说明：

- 验签成功只说明通知可信，仍要结合业务状态机和幂等保护更新订单。

## TP-CB-005: 回调响应格式必须 application/json

- **业务场景**: 回调通知
- **错误码/现象**: 回调重复推送，商户系统返回非 application/json 格式

**常见原因**
商户回调接口返回的 Content-Type 不是 application/json，或响应体格式不符合华为支付要求，导致支付平台认为回调失败并触发重试机制。

**解决步骤**

1. 检查回调接口响应头，确保 Content-Type 为 application/json
2. 确认响应体为 JSON 格式，包含 resultCode 和 resultDesc 字段
3. 测试回调接口响应格式，验证支付平台不再重复推送

**官方文档**

- [回调通知处理](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/payment-callback)

## TP-CB-006: 回调响应体必须 {"resultCode":"000000","resultDesc":"Success."}

- **业务场景**: 回调通知
- **错误码/现象**: 回调响应体格式错误，如返回 resultCode 为 "0" 或 resultDesc 为 "success"（小写）

**常见原因**
商户回调接口返回的响应体字段值与华为支付要求不一致，如 resultCode 应为 "000000"（6位0）而非 "0"，resultDesc 应为 "Success."（首字母大写+句号）而非 "success"。

**解决步骤**

1. 检查回调响应体，确保 resultCode 为 "000000"
2. 确认 resultDesc 为 "Success."（注意大小写和句号）
3. 测试回调接口，验证支付平台不再重复推送

**官方文档**

- [回调通知处理](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/payment-callback)

## TP-CB-007: 回调加密套件不一致导致回调失败

- **业务场景**: 回调通知
- **错误码/现象**: 回调验签失败，商户系统无法解密回调数据

**常见原因**
商户回调接口的加密套件配置与华为支付平台不一致（如 TLS 版本、加密算法不匹配），导致回调数据传输失败或验签失败。

**解决步骤**

1. 检查商户回调接口的 TLS 版本配置（建议 TLS 1.2+）
2. 确认加密套件与华为支付平台支持列表一致
3. 联系华为支付技术支持确认平台端加密配置
4. 更新商户端加密套件配置并测试

**官方文档**

- [回调通知处理](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/payment-callback)

## TP-CB-008: 回调地址必须 HTTPS

- **业务场景**: 回调通知
- **错误码/现象**: 回调地址配置为 HTTP，支付平台拒绝发送回调

**常见原因**
商户回调地址使用 HTTP 协议而非 HTTPS，出于安全考虑华为支付平台拒绝向非 HTTPS 地址发送回调通知。

**解决步骤**

1. 将回调地址从 HTTP 改为 HTTPS
2. 确保证书有效且域名匹配
3. 更新预下单/预签约请求中的 callbackUrl 参数
4. 测试回调接收情况

**官方文档**

- [回调通知处理](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/payment-callback)

## TP-CB-009: 回调验签 demo 与华为支付公钥使用

- **业务场景**: 回调通知
- **错误码/现象**: 商户找不到回调验签示例代码，或华为支付公钥无法打开

**常见原因**
商户在接入回调验签时，找不到官方验签示例代码，或下载的华为支付公钥文件无法直接用文本编辑器打开（实为二进制格式）。

**解决步骤**

1. 参考官方文档中的验签示例代码（Java/Python/PHP）
2. 华为支付公钥文件应使用代码加载而非文本编辑器打开
3. 确认公钥格式为 PEM 或 DER，使用正确的加载方式
4. 检查验签算法（SM2/RSA）与签名算法一致

**官方文档**

- [签名与验签规则](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/payment-certificates-config)
- [回调通知处理](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/payment-callback)
