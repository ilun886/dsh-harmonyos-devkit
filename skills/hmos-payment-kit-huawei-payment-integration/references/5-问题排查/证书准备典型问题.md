# 证书准备典型问题

## TP-CERT-001: 联盟进件二级商户无证书上传入口

- **业务场景**: 证书准备
- **错误码/现象**: 通过华为开发者联盟官网进件的商户，在商户平台找不到证书上传入口

**常见原因**
通过华为开发者联盟官网进件的商户属于二级商户（特约商户），二级商户平台不直接提供证书上传入口。证书需由服务商或平台商统一管理。

**解决步骤**

1. 确认商户入网渠道：联盟进件 vs 商户平台直接入网
2. 联盟进件的二级商户需联系服务商，由服务商上传证书
3. 如需独立接入华为支付，需在华为支付商户平台重新入网（直连商户/服务商/平台类商户）

**官方文档**

- [商户入网申请](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/payment-merc-regist-apply)

## TP-CERT-002: 特约商户证书需服务商登录上传

- **业务场景**: 证书准备
- **错误码/现象**: 特约商户在商户平台找不到证书上传页面

**常见原因**
特约商户的证书管理权限在服务商账户下，特约商户需使用服务商商户号登录商户平台才能看到证书上传入口。

**解决步骤**

1. 使用服务商商户号登录商户平台
2. 在服务商管理页面找到证书上传入口
3. 为特约商户上传证书
4. 获取商户证书编号（auth_id）

**官方文档**

- [证书配置指南](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/payment-certificates-config)

## TP-CERT-003: 商户公钥自生成与上传流程

- **业务场景**: 证书准备
- **错误码/现象**: 商户不确定公钥如何生成和上传

**常见原因**
商户需要自行生成公私钥对，然后将公钥上传到华为商户平台，平台返回商户证书编号（auth_id）用于后续签名验签。

**解决步骤**

1. 商户自行生成 RSA 或 SM2 公私钥对
2. 登录商户平台，上传商户公钥
3. 平台返回商户证书编号（auth_id）
4. 保存私钥用于签名，保存 auth_id 用于请求签名

**官方文档**

- [证书配置指南](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/payment-certificates-config#section08051431101916)

## TP-CERT-004: 商户证书 auth_id 含义与获取

- **业务场景**: 证书准备
- **错误码/现象**: 商户不清楚 MERC_AUTH_ID 的含义和获取方式

**常见原因**
MERC_AUTH_ID（商户证书编号）是商户上传公钥后华为支付平台返回的唯一标识，用于请求签名时标识使用哪个商户证书。

**解决步骤**

1. 商户生成公私钥对
2. 在商户平台上传公钥
3. 平台返回商户证书编号（auth_id）
4. 在预下单等请求签名时使用此 auth_id

**官方文档**

- [证书配置指南](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/payment-certificates-config)

## TP-CERT-005: 华为支付公钥打开方式（右键编辑）

- **业务场景**: 证书准备
- **错误码/现象**: 下载的华为支付公钥文件无法直接打开

**常见原因**
华为支付公钥文件可能为二进制格式，不能直接点击打开。应通过代码加载或右键编辑方式获取内容。

**解决步骤**

1. 不要直接双击打开公钥文件
2. 右键 → 用文本编辑器（如 Notepad++）打开查看
3. 或在代码中直接加载公钥文件（推荐）
4. 确认公钥格式为 PEM 或 DER，选择正确的加载方式

**官方文档**

- [证书配置指南](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/payment-certificates-config)

## TP-CERT-006: 服务商绑定特约商户 appId

- **业务场景**: 证书准备
- **错误码/现象**: 服务商不确定如何绑定特约商户的 appId

**常见原因**
服务商模式下预下单需要传递 spAppId（服务商 appId）和 subAppId（特约商户 appId）。服务商可以绑定特约商户的 appId，也可以申请自己的appId。

**解决步骤**

1. 服务商可绑定特约商户的 appId，也可以新申请一个 appId
2. 如不申请服务商 appId，可绑定特约商户 appId 作为 spAppId
3. 在商户平台完成 appId 与商户号的绑定关系
4. 预下单时正确传递 spAppId 和 subAppId

**官方文档**

- [商户入网申请](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/payment-merc-regist-apply)

## TP-CERT-007: 异主体关联 appId 申请

- **业务场景**: 证书准备
- **错误码/现象**: appId 主体与商户主体不一致，无法绑定

**常见原因**
appId 注册的主体（如天府通金融支付公司）与商户平台注册的主体（如天府通数科公司）不一致，平台拒绝绑定。需申请异主体关联。

**解决步骤**

1. 确认 appId 主体与商户主体是否一致
2. 如不一致，需申请异主体关联
3. 参考官方文档提交异主体关联申请
4. 审核通过后完成 appId 绑定

**官方文档**

- [异主体关联申请](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/payment-merc-regist-apply)
