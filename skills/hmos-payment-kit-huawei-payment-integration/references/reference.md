# Huawei Payment / HarmonyOS Payment Service Reference

## 使用方式

这个文件是当前版本的顶层参考入口。`SKILL.md` 负责触发、路由和高优先级约束；详细规则、事实清单、排障资料和接入说明已经拆到 `references/` 资源层。

术语约定：

- `华为支付`
- `鸿蒙支付服务`
- `HarmonyOS Payment Kit`

在本技能里默认按同一主题处理，只是用户口径不同。

建议使用顺序：

1. 先判断业务场景与端类型。
2. 再按主题进入对应规则文档。
3. 需要代码时再去 `examples.md` 或各场景 `接口索引.md`。
