# WebviewController

Web组件控制器，提供控制Web组件行为的接口，包括enableAdsBlock()等广告过滤相关方法。

## 核心要点

- Web 组件控制器，通过 `controller` 属性绑定到 Web 组件
- `enableAdsBlock()` 方法控制广告过滤开关
- 广告过滤相关能力需配合 `AdsBlockManager` 和 `onAdsBlocked()` 回调使用

详细文档请参见：[WebviewController - 华为开发者文档](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/arkts-apis-webview-webviewcontroller)
