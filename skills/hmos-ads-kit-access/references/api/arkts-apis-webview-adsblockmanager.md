# AdsBlockManager

提供自定义广告过滤配置、控制网站级广告过滤特性的全局单例类。

## 核心要点

- 用于 Web 组件中的广告过滤能力管理
- 支持自定义广告过滤规则配置，以及开启/关闭网站级广告过滤
- 与 `web-adsblock.md` 文档配套使用

详细文档请参见：[AdsBlockManager - 华为开发者文档](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/arkts-apis-webview-adsblockmanager)
