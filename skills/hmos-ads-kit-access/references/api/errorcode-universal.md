# 通用错误码

通用错误码说明，包含401、801等常见错误码的定义和处理建议。

## 核心要点

| 错误码 | 说明 |
| ------ | ---- |
| 401 | 参数错误：必选参数未指定、参数类型错误或校验失败 |
| 801 | 能力不支持：当前设备/系统不支持所调用的能力 |

- 广告相关错误码（21800001-21800005）见 `api/errorcode-ads.md`
- OAID 错误码（17300001/17300002）见 `api/errorcode-oaid.md`

详细文档请参见：[通用错误码 - 华为开发者文档](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/errorcode-universal)
