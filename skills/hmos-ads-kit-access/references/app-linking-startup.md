# App Linking启动

使用App Linking实现应用启动的方式。

## 核心要点

- App Linking 是华为提供的跨应用跳转方案，可通过链接拉起指定应用
- 应用启动场景：用户点击 App Linking 链接时，若应用已安装则直接拉起；未安装则跳转应用市场/网页
- 与广告场景的关联：广告跳转（落地页、应用下载）可借助 App Linking 实现深链跳转
- 相关能力：直达 AppGallery、延迟深度链接、社交分享跳转

详细文档请参见：[App Linking启动 - 华为开发者文档](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/app-linking-startup)
