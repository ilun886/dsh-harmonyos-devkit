# 模拟器规格

IDE模拟器的规格说明和使用指南。

## 核心要点

- 华为 DevEco Studio 提供 HarmonyOS 模拟器，支持手机、平板、2in1 等设备形态
- 模拟器用于应用开发调试，广告功能可在模拟器上调试（部分依赖真实设备能力的功能可能受限，如 OAID 需真机验证）
- 模拟器资源消耗较高，建议使用满足规格要求的主机配置

详细文档请参见：[模拟器规格 - 华为开发者文档](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-emulator-specification)
